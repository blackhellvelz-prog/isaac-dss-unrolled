# Dead Sea Scrolls: Unrolled

The Binding of Isaac: Repentance+ mod (REPENTOGON). Author: blackhellvelz.

English · [Русский](#русский)

Dead Sea Scrolls (DSS) is the menu many big mods use — Fiend Folio, Epiphany, IPECAC, Heaven's Call, Encyclopedia, Alt Horsemen and others. This mod unrolls it into a wide parchment scroll.

### What changes
- **A grid of hand-drawn icons with captions** instead of a long text list — pages flip left and right.
- **One window for all mods**: every installed mod that has a DSS menu, a Mod Config Menu section or Passive Skill Trees is a tile with the mod's Workshop picture; open any of them from one place.
- Settings, changelogs and pages of every DSS mod work as before — only the look changes.
- The scroll title, the tip panel and all menu text follow the game language (English or Russian). Russian letters in DSS use the Cyrillic font from Mod Translator; without it the menu stays in English.


### Requirements
- [REPENTOGON](https://steamcommunity.com/sharedfiles/filedetails/?id=3127536138)
- any mod with a Dead Sea Scrolls menu (otherwise there is nothing to show)

Only mods you actually have installed are shown in the window.

### Links
Source code: [GitHub](https://github.com/blackhellvelz-prog/isaac-dss-unrolled)
More from the same set: Basement Scrapbook Menu, Talents for Everyone, Peat, Isaac-Style, Mod Fixes & Speedups, Russian Translation for Mods.

Pictures of popular mods are used in the Mods menu and the DSS window — thanks to their creators and the Isaac modding community!

## Install

Subscribe on Steam Workshop — that's all. To install by hand, copy this folder into `The Binding of Isaac Rebirth/mods/`.

## Repository

This repository is the mod folder itself: `main.lua` is the entry point, the other `.lua` files are its modules, `resources/` — pictures, `metadata.xml` — the Workshop page. Pictures that belong to the game or to other mods are not stored here. Other mods this one works with — [CREDITS.md](CREDITS.md). Code license — [LICENSE](LICENSE) (MIT).

## Русский

Dead Sea Scrolls (DSS) — меню, которым пользуются многие большие моды: Fiend Folio, Epiphany, IPECAC, Heaven's Call, Encyclopedia, Alt Horsemen и другие. Этот мод разворачивает его в широкий пергаментный свиток.

### Что меняется
- **Сетка рисованных значков с подписями** вместо длинного списка — страницы листаются влево и вправо.
- **Одно окно для всех модов**: каждый установленный мод с меню DSS, разделом Mod Config Menu или деревьями Passive Skill Trees — плитка с его картинкой из Мастерской; открыть любое можно из одного места.
- Настройки, журналы изменений и страницы любого мода DSS работают как раньше — меняется только вид.
- Заголовок свитка, панель-подсказка и весь текст меню — на языке игры (русский или английский). Русские буквы в DSS — шрифтом с кириллицей из Mod Translator; без него меню остаётся английским.


### Нужно
- [REPENTOGON](https://steamcommunity.com/sharedfiles/filedetails/?id=3127536138)
- любой мод с меню Dead Sea Scrolls (иначе показывать нечего)

В окне — только моды, которые у вас установлены.
